Use the `story-writing` skill on this request:

$ARGUMENTS

1. Fill in the template **As a ⟨role⟩, I want ⟨capability⟩, so that ⟨benefit⟩** using only what's stated or what you ask for and get — never invent a role, restate the capability as the benefit, or guess unstated technical detail.
2. If any slot isn't grounded in something said, ask for it before writing the story. Ask one question at a time, not all three at once.
3. If this is really more than one story, say so and stop — don't fold multiple asks into one sentence.
4. Write the filled-in template back and ask for confirmation before moving on.
5. Say what's next: right-sized → `estimation` to score it; too big → `story-slicing` to cut it first.

Wait for confirmation before treating the story as final.
